# Environment-variable reference

> Generated by `pkg/config/envoverlay` — do not edit by hand. Regenerate with
> `go test ./pkg/config/envoverlay -run EnvVarReference -update`.

Every config field is overridable by an environment variable whose name is derived from its
YAML path (dashes become `_`, upper-cased, prefix-joined). Env vars **override** the YAML file,
and the YAML file is **optional** (env-only boot works). Precedence: real env > `.env` > YAML.
See [D-EnvConfig](../architecture/decisions.md).

`_N_` marks a slice index (e.g. `_0_`); `_<KEY>_` marks a map key. In addition, the database
connection can be assembled from discrete parts: `<PREFIX>_DB_HOST`, `_DB_PORT`, `_DB_USER`,
`_DB_PASSWORD`, `_DB_NAME`, `_DB_SSLMODE` (used only when `<PREFIX>_POSTGRES_DSN` is unset).
